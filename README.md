# API Connect

## Objetivo
A API Connect é uma API REST simples desenvolvida como MVP para demonstrar operações básicas de cadastro, listagem, consulta, atualização e exclusão de usuários, utilizando persistência em memória.

## Tecnologias utilizadas
- Python
- Flask
- JSON
- Git
- GitHub
- Thunder Client
